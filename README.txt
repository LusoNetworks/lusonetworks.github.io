LusoNetworks — repository
=========================

The live website is in the /docs folder — that is what GitHub Pages serves.
See docs/README.md for full setup and deploy instructions.

QUICK START
  1. Edit your WhatsApp number + email in docs/assets/app.js (lines marked EDIT-ME).
  2. Find-and-replace USERNAME.github.io with your real Pages host across
     the docs/*.html, docs/robots.txt and docs/sitemap.xml files.
  3. GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /docs.
